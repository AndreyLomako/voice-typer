# Безопасность VoiceTyper hs

Этот документ описывает, какие данные обрабатывает программа, куда они уходят и какие меры защиты приняты. Последний аудит проведён для версии 1.2.0.

## Какие данные и куда идут

| Данные | Где обрабатываются | Хранятся ли |
|---|---|---|
| Звук с микрофона | В памяти, только во время записи. В локальном режиме не покидает компьютер. | Нет, после распознавания удаляется. |
| Распознанный текст | Вставляется в выбранное поле. Последние 100 фраз видны в разделе «История». | Только в памяти до закрытия программы; на диск не пишется. |
| Нажатия клавиш | Хук ОС проверяет только, совпадает ли нажатие с горячей клавишей. | Нет. Клавиши не записываются и не передаются. |
| API-ключ облака | Отправляется только на указанный вами адрес API и только по HTTPS. | Windows — DPAPI (зашифрован под вашу учётную запись), macOS — Связка ключей, Linux — Secret Service. |
| Журнал программы | Технические события: загрузка модели, ошибки, длина распознанного текста. | Да, в папке настроек, до 3 МБ. Текст диктовки и ключи в журнал не пишутся. |

**Сеть.** В локальном режиме программа выходит в интернет только для скачивания модели с Hugging Face, один раз. Телеметрии нет.

**Облачный режим.** Аудио отправляется выбранному провайдеру: OpenAI, Groq или вашему серверу. Это ваш осознанный выбор, и его условия обработки данных действуют независимо от программы.

## Меры защиты

- **Модели закреплены по хешу коммита.** Если репозиторий модели на Hugging Face изменят или подменят, программа всё равно скачает проверенную версию файлов. Формат моделей CTranslate2 не исполняет код при загрузке, в отличие от pickle.
- **Ключ не уходит по открытому каналу.** Программа отказывается отправлять ключ по `http://` на любые адреса, кроме `localhost`. Редиректы отключены: ключ и аудио уходят только на указанный адрес.
- **Приватный буфер обмена (Windows).** Продиктованный текст помечается как исключённый из журнала Win+V, облачной синхронизации буфера и сторонних менеджеров буфера. После вставки возвращается прежнее содержимое буфера, включая картинки и скопированные файлы.
- **Безопасный ввод.** Из распознанного текста удаляются переводы строк, управляющие символы и невидимые символы смены направления текста (атака «Trojan Source»). Поэтому вставка в терминал не может сама «нажать Enter» и выполнить команду.
- **Устойчивость к повреждённым настройкам.** Значения неверного типа в `settings.json` игнорируются. Имя модели проверяется по белому списку, чтобы подменённое значение не превратилось в путь к файлу.
- **Права на файлы.** На macOS и Linux файлы настроек и журнала доступны только владельцу (`chmod 600`).
- **Один экземпляр в пределах сеанса.** Другой пользователь того же компьютера не может помешать запуску программы.
- **Зависимости проверяются** через `pip-audit` при каждой сборке в GitHub Actions. На момент аудита известных уязвимостей не найдено.
- **Контрольные суммы.** Вместе с релизом публикуется `SHA256SUMS.txt`.

## Что важно знать

- **Глобальный перехват клавиатуры.** Это основа работы горячих клавиш, поэтому антивирусы иногда помечают такие программы как подозрительные. Исходный код открыт; в коде видно, что события клавиш не сохраняются и не передаются.
- **Файлы не подписаны.** Windows SmartScreen и macOS Gatekeeper покажут предупреждение. Для полной уверенности сверяйте `SHA256SUMS.txt` или собирайте программу сами (`python build.py`).
- **Клик в режиме «под мышку».** Программа кликает туда, где был указатель в момент окончания записи. Не отпускайте клавишу записи, наведя мышь на кнопки, нажатие которых нежелательно.
- **Права администратора** программе не нужны и не запрашиваются.
