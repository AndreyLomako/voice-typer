# 🎙 VoiceTyper hs — голосовой ввод в любое поле

**Windows · macOS · Linux** · **Разработчик:** Andrey Lomako — fullstack-development

Наведите мышь на нужное поле, зажмите горячую клавишу и говорите. Отпустите, и распознанный текст появится там, куда указывает мышь. Работает в любых программах: браузер, мессенджеры, Word, IDE, 1С и т.д.

- **Офлайн и бесплатно.** Распознаёт локальная модель Whisper (faster-whisper), аудио никуда не отправляется.
- **Облако по желанию.** Можно подключить OpenAI, Groq или любой OpenAI-совместимый сервер.
- **Удобные горячие клавиши:** режим рации (держать), режим переключателя (нажал / нажал), отмена.
- **Вставка «под мышку»** или в активное поле ввода, через буфер обмена или эмуляцию набора.
- **Индикатор у курсора** показывает уровень громкости, таймер и статус распознавания.
- **Значок в трее** (на macOS — в Dock), автозапуск, тёмная и светлая темы, история фраз.

| | |
|---|---|
| **Стоимость** | Бесплатно, лицензия MIT. Локальное распознавание работает без интернета и без оплаты. Платным может быть только облачный режим, по тарифам выбранного провайдера (OpenAI, Groq). |

Одна программа и один исходный код, три сборки. Платформенный код загружается только на своей ОС, поэтому версии не мешают друг другу и не добавляют лишнего веса.

## Скачать

Страница [Releases](../../releases/latest):

| ОС | Файл |

Рядом лежит `SHA256SUMS.txt` с контрольными суммами файлов.

### Windows

Запустите `VoiceTyper-hs.exe`, установка не нужна.

> SmartScreen может предупредить о неподписанном файле: «Подробнее» → «Выполнить в любом случае».

### macOS

1. Распакуйте архив и перетащите **VoiceTyper hs.app** в «Программы».
2. Первый запуск: правый клик по приложению → «Открыть» → «Открыть». Приложение не нотарифицировано Apple, поэтому двойной клик в первый раз его заблокирует.
3. Разрешите в «Системные настройки → Конфиденциальность и безопасность»:
   - **Микрофон** — для записи речи;
   - **Универсальный доступ** — для клика и вставки текста;
   - **Мониторинг ввода** — для горячих клавиш.

   После выдачи разрешений перезапустите программу.

Значка в строке меню нет: программа живёт в Dock, клик по значку открывает настройки.

### Linux

```sh
tar xzf VoiceTyper-hs-linux-x86_64.tar.gz
cd VoiceTyper-hs && ./install.sh      # в ~/.local/bin + ярлык в меню, без sudo
sudo apt install libportaudio2 xclip  # Ubuntu/Debian (Fedora: portaudio xclip)
```

Нужна **сессия X11** (Xorg). В Wayland система не даёт программам перехватывать глобальные клавиши и вводить текст в чужие окна. На Ubuntu выберите «Ubuntu on Xorg» на экране входа (значок шестерёнки).

Также нужен любой микрофон. Интернет нужен только для первого скачивания модели или для облачного режима.

## Как пользоваться

| Действие | Windows / Linux | macOS |
|---|---|---|
| Держать — запись, отпустить — вставка | **Правый Ctrl** | **Правый Option** |
| Начать / закончить запись (длинная диктовка) | **Ctrl + Alt + Space** | **Ctrl + Option + Space** |
| Отменить запись | **Esc** | **Esc** |

Все комбинации меняются в настройках: нажмите на кнопку с комбинацией и нажмите новые клавиши.
Если во время удержания клавиши рации нажать любую другую клавишу (например, Правый Ctrl + C), запись отменится. Так обычные сочетания клавиш не мешают диктовке.

Окно настроек открывается двойным кликом по значку в трее (на macOS — кликом по значку в Dock). Если закрыть окно крестиком, программа продолжит работать в фоне. Цвет значка в трее показывает состояние: синий — готово, красный — идёт запись, оранжевый — распознавание.

Та же инструкция, системные требования и контакты есть в самом приложении, в разделе **«Справка»**.

## Настройки

- **Распознавание:** движок (локально или облако), модель, CPU/GPU, язык, «подсказка-словарь» для имён и терминов, выбор и проверка микрофона.
- **Горячие клавиши:** три комбинации, общий выключатель, максимальная длительность записи.
- **Вставка текста:** куда (под указатель мыши или в активное поле), как (Ctrl+V/Cmd+V или эмуляция набора), восстановление буфера обмена, пробел в конце, удаление финальной точки.
- **Облако (API):** провайдер, адрес, модель, ключ (хранится в Windows DPAPI / Связке ключей macOS / Secret Service Linux) и проверка подключения.
- **Интерфейс:** тема, индикатор, звуки, автозапуск, запуск в фоне.
- **Справка:** инструкция с вашими текущими клавишами, системные требования, разработчик.

### Какую модель выбрать

| Модель | Размер | Комментарий |
|---|---|---|
| tiny | 75 МБ | очень быстро, но много ошибок |
| base | 145 МБ | быстро, для простых фраз |
| **small** | 480 МБ | **оптимально для большинства ПК** |
| medium | 1.5 ГБ | точнее, на CPU в 2–3 раза медленнее |
| large-v3-turbo | 1.6 ГБ | высокая точность, лучше с видеокартой |
| large-v3 | 3 ГБ | максимум точности, нужна видеокарта |

## Безопасность и приватность

Коротко: в локальном режиме звук и текст не покидают компьютер, ключ API хранится в зашифрованном виде, а продиктованный текст не попадает в журнал буфера обмена. Подробности — в [SECURITY.md](SECURITY.md).

## Известные ограничения

- Горячие клавиши не блокируются для других программ. Выбирайте редко используемые клавиши: Правый Ctrl, Правый Alt/Option, F9, Pause.
- **Windows:** в окнах, запущенных от имени администратора, горячие клавиши и вставка работают, только если VoiceTyper тоже запущен от администратора.
- **macOS:** в некоторых нативных программах первый клик по неактивному окну только активирует его. Если текст не вставился, включите «Вставка текста → В активное поле ввода». Intel-Mac сейчас не поддерживаются.
- **Linux:** только X11. В терминалах вставка — Ctrl+Shift+V, поэтому для них выберите «Эмуляция набора».

## Сборка из исходников

Нужен Python 3.11+ (проверено на 3.12 и 3.14). Сборка выполняется на той ОС, для которой нужна программа:

```sh
git clone https://github.com/AndreyLomako/voice-typer.git
cd voice-typer
python -m venv .venv && . .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt pyinstaller
python build.py --smoke                           # результат — в папке release/
```

На Windows то же самое делает `build.bat`. Все три версии автоматически собирает GitHub Actions (`.github/workflows/build.yml`) при публикации тега `v*`. Каждая сборка проверяется распознаванием тестовой фразы и аудитом зависимостей.

Запуск без сборки: `python -m voicetyper`. Диагностика распознавания без интерфейса: `VoiceTyper-hs --transcribe-file input.wav result.txt [модель]`.

## Устройство проекта

```
voicetyper/
  app.py         контроллер: запись → распознавание → вставка
  hotkeys.py     горячие клавиши (различает левый и правый Ctrl/Alt/Shift)
  audio.py       запись с микрофона, 16 кГц mono
  engines.py     faster-whisper (модели закреплены по хешу) и OpenAI-совместимый API
  inserter.py    вставка текста: клик под мышью, вставка или набор
  overlay.py     индикатор у курсора
  ui.py          окно настроек (customtkinter)
  tray.py        значок в трее
  config.py      настройки (JSON)
  system/        всё, что зависит от ОС
    windows.py   WinAPI: хук, буфер обмена, DPAPI, реестр
    macos.py     Quartz Event Tap, CGEvent, LaunchAgent
    linux.py     pynput + Xlib (X11), XDG autostart
    posix.py     общее для macOS/Linux: блокировка, keyring, звук
build.py         сборка под текущую ОС
```
