# 🎙 VoiceTyper hs — голосовой ввод в любое поле Windows

**Разработчик:** Andrey Lomako — fullstack-development

Наведите мышь на нужное поле, зажмите горячую клавишу и говорите. Отпустите, и распознанный текст появится там, куда указывает мышь. Работает в любых программах: браузер, мессенджеры, Word, IDE, 1С и т.д.

- **Офлайн и бесплатно.** Распознаёт локальная модель Whisper (faster-whisper), аудио никуда не отправляется.
- **Облако по желанию.** Можно подключить OpenAI, Groq или любой OpenAI-совместимый сервер.
- **Удобные горячие клавиши:** режим рации (держать), режим переключателя (нажал / нажал), отмена.
- **Вставка «под мышку»** или в активное поле ввода, через буфер обмена или эмуляцию набора.
- **Индикатор у курсора** показывает уровень громкости, таймер и статус распознавания.
- **Значок в трее,** автозапуск, тёмная и светлая темы, история фраз.

## Коротко

| | |
|---|---|
| **Стоимость** | Бесплатно, лицензия MIT. Локальное распознавание работает без интернета и без оплаты. Платным может быть только облачный режим, по тарифам выбранного провайдера (OpenAI, Groq). |
| **Размер** | Программа: 109 МБ (один exe). Модель распознавания скачивается один раз: от 75 МБ до 3 ГБ, по умолчанию small — 480 МБ. |
| **Платформы** | Windows 10 / 11 (64-бит). Linux и macOS не поддерживаются. |
| **Автозапуск** | Есть: «Интерфейс» → «Запускать вместе с Windows». Программа стартует свёрнутой в трей. |

## Системные требования

| | Минимум | Рекомендуется |
|---|---|---|
| ОС | Windows 10 64-бит | Windows 11 |
| Процессор | 64-бит, 4 потока | 8+ потоков (для medium / large) |
| Оперативная память | 4 ГБ (модель small занимает ~1 ГБ) | 8 ГБ и больше для medium / large |
| Диск | 110 МБ + модель (75 МБ – 3 ГБ) | SSD |
| Микрофон | любой: встроенный, USB или гарнитура | гарнитура или USB-микрофон |
| Интернет | только для первого скачивания модели | — |
| Видеокарта | не нужна | NVIDIA с CUDA 12 и cuDNN 9 для моделей large |

## Установка

1. Скачайте `VoiceTyper-hs.exe` со страницы [Releases](../../releases/latest).
2. Запустите. Установка не нужна, программа переносимая.
3. При первом использовании скачается модель распознавания (small — около 480 МБ, один раз).

> Windows SmartScreen может предупредить о неподписанном файле: «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

| Действие | Клавиши по умолчанию |
|---|---|
| Держать — запись, отпустить — вставка | **Правый Ctrl** |
| Начать / закончить запись (длинная диктовка) | **Ctrl + Alt + Space** |
| Отменить запись | **Esc** |

Все комбинации меняются в настройках: нажмите на кнопку с комбинацией и нажмите новые клавиши.
Если во время удержания клавиши рации нажать любую другую клавишу (например, Правый Ctrl + C), запись отменится. Так обычные сочетания клавиш не мешают диктовке.

Окно настроек открывается двойным кликом по значку в трее. Если закрыть его крестиком, программа продолжит работать в трее. Цвет значка показывает состояние: синий — готово, красный — идёт запись, оранжевый — распознавание.

Та же инструкция, системные требования и контакты есть в самом приложении, в разделе **«Справка»**.

## Настройки

- **Распознавание:** движок (локально или облако), модель, CPU/GPU, язык, «подсказка-словарь» для имён и терминов, выбор и проверка микрофона.
- **Горячие клавиши:** три комбинации, общий выключатель, максимальная длительность записи.
- **Вставка текста:** куда (под указатель мыши или в активное поле), как (Ctrl+V или эмуляция набора), восстановление буфера обмена, пробел в конце, удаление финальной точки.
- **Облако (API):** провайдер, адрес, модель, ключ (хранится зашифрованным через Windows DPAPI) и проверка подключения.
- **Интерфейс:** тема, индикатор, звуки, автозапуск, запуск свёрнутым.
- **Справка:** инструкция с вашими текущими клавишами, системные требования, разработчик.

### Какую модель выбрать

| Модель | Размер | Комментарий |
|---|---|---|
| tiny | 75 МБ | очень быстро, но много ошибок |
| base | 145 МБ | быстро, для простых фраз |
| **small** | 480 МБ | **оптимально для большинства ПК** |
| medium | 1.5 ГБ | точнее, на CPU в 2–3 раза медленнее |
| large-v3-turbo | 1.6 ГБ | высокая точность, лучше с видеокартой |
| large-v3 | 3 ГБ | максимум точности, нужна видеокарта |

Для GPU (NVIDIA) должны быть установлены CUDA 12 и cuDNN 9. Если они недоступны, программа сама переключится на CPU.

## Файлы

- Настройки и журнал: `%APPDATA%\VoiceTyper\`
- Модели: `%LOCALAPPDATA%\VoiceTyper\models\`

## Известные ограничения

- В окнах, запущенных от имени администратора, горячие клавиши и вставка работают, только если VoiceTyper тоже запущен от администратора (ограничение Windows).
- Горячие клавиши не блокируются для других программ. Выбирайте редко используемые клавиши: Правый Ctrl, Правый Alt, F9, Pause.

## Сборка из исходников

Нужен Python 3.11+ (проверено на 3.14):

```bat
git clone https://github.com/AndreyLomako/voice-typer.git
cd voice-typer
build.bat
```

Готовый файл появится в `dist\VoiceTyper-hs.exe`. Запуск без сборки:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m voicetyper
```

Диагностика распознавания без интерфейса: `VoiceTyper-hs.exe --transcribe-file input.wav result.txt`.

## Устройство проекта

```
voicetyper/
  app.py       контроллер: запись → распознавание → вставка
  hotkeys.py   глобальные горячие клавиши (различает левый и правый Ctrl/Alt/Shift)
  audio.py     запись с микрофона, 16 кГц mono
  engines.py   faster-whisper и OpenAI-совместимый API
  inserter.py  вставка текста: клик под мышью, Ctrl+V или набор
  overlay.py   индикатор у курсора (не забирает фокус, пропускает клики)
  ui.py        окно настроек (customtkinter)
  tray.py      значок в трее
  config.py    настройки (JSON), vault.py: шифрование ключа (DPAPI)
```
